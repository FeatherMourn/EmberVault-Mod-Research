SOURCE FACTS

Current raw shell action:

```powershell
Register-SafeUiEvent $script:btnScannerToggle "Click" {
    ...
    $isActive = [NativeMemoryEngine]::ToggleScanner()
    ...
}
```

Native scanner behavior is mutation-coupled:

- `ToggleScanner()` -> `EnableScanner()` / `DisableScanner()`
- `EnableScanner()` may start `StartMemorySweeper()`
- sweeper calls `ResolveAll()` and can tick active autorun/auto-loot paths
- `DisableScanner()` calls:
  - `StopMemorySweeper()`
  - `UninstallPositionHook()`
  - `RevertAll()`
- `UninstallPositionHook()` can restore executable bytes / free remote storage
- `RevertAll()` reverts all active registered patches and clears bridge toggles

Therefore this is not a safe enabled diagnostic toggle.
