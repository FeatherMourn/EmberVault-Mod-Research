A. CODEX DETAIL BINDING LIFETIME

`Update-CodexDetails` repeatedly executes:

`$pnlDetail.Controls.Clear()`

without clearing the whole F7 PAGE.

Dynamic detail action EventIds differ by selected command, so old active bindings can otherwise remain in `$script:f7ActiveBindings`.

Before `$pnlDetail.Controls.Clear()`, remove active bindings that belong specifically to:

- Page = `Codex & Commands`
- LifetimeScope = `DETAIL`

Use a narrow fail-safe loop over a snapshot of the keys.

Example shape:

```powershell
foreach ($eventId in @($script:f7ActiveBindings.Keys)) {
    $binding = $script:f7ActiveBindings[$eventId]
    if ($binding.Page -eq "Codex & Commands" -and $binding.LifetimeScope -eq "DETAIL") {
        $script:f7ActiveBindings.Remove($eventId)
    }
}
```

Equivalent implementation is acceptable.

Do NOT remove SHELL bindings.
Do NOT remove unrelated PAGE bindings.
Do NOT delete stable event definitions; only clear active DETAIL bindings.

Then clear/rebuild the detail panel.

All controls created inside `Update-CodexDetails` must use:
- Page = `Codex & Commands`
- LifetimeScope = `DETAIL`
