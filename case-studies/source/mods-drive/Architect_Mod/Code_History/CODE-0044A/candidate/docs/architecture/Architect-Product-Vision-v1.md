# Architect Toolkit — Product Vision v1

**Document type: VISION.** This is product direction, not proof of current
functionality. Engineering status is maintained separately in
`Architect-Engineering-State-1076226.md`.

## Creative philosophy

Architect should enable creativity rather than replace creativity. The tool
reduces repetitive work, makes intent precise, and keeps the player in charge
of the creative decision. Enshrouded remains the world, placement, validation,
authority, and persistence host wherever a capability is validated.

## Creative workflow

```
Sketch → Plan → Shape → Structure → Roof → Materials → Interior → Decor
       → Landscape → Lighting → Detail → Review → Share
```

F8 is the fast workspace for an in-world task. F7 is the slower project,
research, and administration workspace.

## F8 conceptual organization

- **BUILD** — select, construct, transform, pattern, measure and align.
- **CREATE** — primitives, procedural forms, composer, patterns, sculpt.
- **DESIGN** — materials, interior, facade, decor, lighting.
- **ENVIRONMENT** — terrain, paths and roads, landscape, botanical, surface detail, water.
- **PROJECT** — overview, layers, phases, structures, history, versions, collaboration.
- **STUDY** — inspect, survey, recorder, resources, measurements, research.

Second-level navigation is an information architecture, not a promise that
each entry already has a backend module. Existing operations should be reused,
extended, composed, augmented, or replaced only when evidence supports that
choice.

## F7 conceptual organization

F7 provides Project Manager, Blueprint Library, Codex/Search, Map/Wayfinder,
Settings/Profiles/Modules, Developer, Admin, and Diagnostics.

## Product guardrails

Architect owns workflow, intent, planning, precision, assistive logic,
project semantics, preview orchestration, history, collaboration, and UI.
The game should own world authority, placement, terrain mutation, entity
lifecycle, inventory semantics, map rendering, camera behavior, movement,
validation, network authority, and persistence when validated.

See `docs/architecture/README.md` for the evidence and roadmap indexes.
