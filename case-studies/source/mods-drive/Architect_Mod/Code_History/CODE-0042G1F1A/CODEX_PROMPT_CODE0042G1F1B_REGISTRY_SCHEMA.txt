- `numeric` -> choose `integer` when valueType is integer, otherwise `float`

Do not change existing valid `toggle`, `button`, `dropdown`, `read_only`, etc.

B. evidenceStatus

Do not preserve custom engineering labels in the enum field.

Required conservative mapping:
- `BUILD_GATED` -> `UNSOLVED`
- `ADM-TEST-0002` -> `UNSOLVED`
- `SEMANTIC_MISMATCH` -> `EXPERIMENTAL`

- `STARTUP_CANARY_ONLY` -> `EXPERIMENTAL`
  - preserve STARTUP_CANARY_ONLY wording in description/failureReason
- `ORCHESTRATION_ONLY` -> `EXPERIMENTAL`
  - preserve ORCHESTRATION_ONLY wording in description/failureReason

C. runtimeMode

- `STARTUP` is not a valid v2 runtime mode.
- For `cheat.autoloot.toggle`, use `UNAVAILABLE` because the F7 live action is intentionally unavailable; preserve startup-canary semantics in failureReason/description.

D. authority

Normalize non-schema descriptive values conservatively:
- `native_runtime` -> `unknown`
- `startup_canary` -> `unknown`
- `unresolved` -> `unknown`
- `none` -> `unknown`

Do not infer `local`, `host`, or `server` without accepted authority evidence.

E. backend

For disabled/unqualified actions currently using descriptive pseudo-backends:
- `NATIVE_CORRELATION` -> `NONE`
- `EXISTING_DISPATCH_ONLY` -> `NONE`

Preserve correlation/orchestration details in failureReason/description.

Do NOT invent `NATIVE_MEMORY` or `NATIVE_HOOK` merely because legacy code contains native paths. Backend fields describe accepted canonical execution ownership, not every historical implementation clue.

F. backendAdapter

Normalize adapter names to the existing `New-AdminAdapterTable` vocabulary.

Use domain-appropriate existing adapters without changing enablement. Suggested conservative mapping:

- `ItemAdapter` -> `InventoryAdapter`
- `NativeCorrelationAdapter`:
  - movement actions -> `MovementAdapter`
  - teleport/travel -> `TravelAdapter`
  - player/vitals/survival/combat toggles -> `PlayerAdapter`
  - skill/crafting actions -> `CraftingAdapter` where appropriate
  - world/time/plant actions -> `WorldAdapter`
  - altar/build range -> `BuildingAdminAdapter`
- `StartupCanary` -> `InventoryAdapter` for Auto Loot
- `None`:
  - glider stamina -> `GliderAdapter`
  - teleport -> `TravelAdapter`
  - position read -> `MovementAdapter`
- `ArchitectPresetAdapter` -> `DiagnosticsAdapter` (internal admin orchestration, backend remains NONE)

If a row does not map cleanly, keep it disabled and choose the closest existing domain adapter. Do not add a new adapter class/name in this pass.
