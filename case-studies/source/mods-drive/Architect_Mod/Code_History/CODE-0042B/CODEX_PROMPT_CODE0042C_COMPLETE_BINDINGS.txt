IMPORTANT DISTINCTION
Not every clickable/control event belongs in the canonical gameplay action registry.

ACTION CONTROLS include any F7 control that can:
- call `Send-CheatCommand`, `Dispatch-AdminCommand`, or equivalent gameplay/admin dispatcher;
- request a backend operation that changes or observes Enshrouded/Architect runtime state;
- arm/end/mark a runtime capture or diagnostic action represented in the canonical registry;
- invoke a compound admin action/preset represented as an action.

UI-ONLY CONTROLS include:
- navigation buttons;
- text search/filter boxes;
- list/grid selection changes;
- sorting/filtering/view changes;
- opening an external URL;
- local page navigation that does not invoke a game/admin capability.

Do NOT invent fake ActionIds for UI-only controls merely to reach 100% coverage.
