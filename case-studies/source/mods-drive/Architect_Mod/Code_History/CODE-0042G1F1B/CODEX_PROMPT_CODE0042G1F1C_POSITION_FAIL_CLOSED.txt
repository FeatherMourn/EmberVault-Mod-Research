GOAL

Make `Get-CurrentPlayerPosition` a genuinely fail-closed, non-mutating shared helper.

This is required because F7 Home currently calls it automatically during render, and the current implementation can install an executable position hook.

SOURCE FACT

Current `Get-CurrentPlayerPosition` calls:

`[NativeMemoryEngine]::ReadPlayerCoordinates(...)`

Current `ReadPlayerCoordinates(...)` in `NativeMemoryEngine.cs` unconditionally calls:

`EnsurePositionHook();`

`EnsurePositionHook()` performs executable native mutation including:
- remote allocation;
- `WriteProcessMemory`;
- executable detour patching;
- protection changes / instruction-cache flush.

Therefore simply rendering Home can currently reach a mutation path.
