# Enshrouded Trainer GUI

Run `Run_Trainer_GUI.bat` from this directory. It uses only the Python
standard library and defaults to the sibling authoritative table:
`..\Enshrouded_Master_Trainer.CT`.

The GUI parses real records, supports search/navigation, displays process
detection, stores its own selected-table configuration, and logs activity.
Cheat Engine activation is intentionally disabled until a supported local
bridge can confirm attachment, table load, and per-record state. No button
reports activation based only on a click.
