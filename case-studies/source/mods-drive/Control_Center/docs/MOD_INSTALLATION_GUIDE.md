# Mod Installation Guide

Use Mod Manager when you want to add, update, disable, or remove a local mod. Control Center keeps the workflow reviewable and preserves a restore point before managed changes.

## Safe installation

1. Close Enshrouded.
2. Open **Mod Manager** and add the folder containing the mod package.
3. Review the package identity, version, loader requirement, dependencies, conflicts, and feature state.
4. Choose **Preview** before installing.
5. Apply only after the preview shows the intended target and files.
6. Launch through Control Center and use Research Lab when the package is experimental or unverified.

Packages marked research-only require explicit research approval. Unsupported or ambiguous packages remain blocked until they are reviewed. Control Center does not silently delete files it does not own.

## Updates and removal

Updates create a restore point before replacing managed files. In the **Installed Mods** view, choose **Restore** to return to the latest restore point; the game must be closed. Removal deletes only files still matching the ownership record, leaving unrelated or user-created files untouched.

If a mod breaks launch, close the game, run Troubleshooter, and use the reversible recovery action before trying another version.
