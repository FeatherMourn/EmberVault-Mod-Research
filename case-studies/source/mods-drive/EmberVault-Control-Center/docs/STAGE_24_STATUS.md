# Stage 24 — Website and Community Integration

Stage 24 establishes a reviewable boundary between the desktop Control Center
and the EmberVault website/community repository.

## Delivered so far

- Website-owned community handoff envelope around the validated public catalog.
- Local staging of the handoff for repository review.
- Conflict comparison that refuses automatic overwrite and marks divergent
  catalog sections for review.
- Control Center action for staging the handoff.
- Versioned research, content, and knowledge submission envelopes that require
  local publication before staging.
- Record-level conflict comparison with discussion-link metadata support.

## Authority and safety

The website remains authoritative for authentication, moderation, discussions,
and remote publication. The desktop emits sanitized public data only; private
records, local paths, save data, and raw runtime evidence are not included.
Conflicts are reviewable and never silently merged or overwritten.

## Remaining Stage 24 work

The website still owns remote authentication, moderation, final publication,
and discussion hosting; the desktop only prepares reviewable handoffs.
