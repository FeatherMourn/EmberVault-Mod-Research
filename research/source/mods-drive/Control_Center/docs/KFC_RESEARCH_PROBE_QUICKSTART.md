# KFC Research Probe — Quick Start

1. Close Enshrouded.
2. Double-click **Install KFC Research Probe.bat** in the Control Center folder.
3. Launch Enshrouded once and wait until the main menu or world loads.
4. Close Enshrouded.
5. Send the newest file from the game's `logs` folder.
6. When finished, double-click **Remove KFC Research Probe.bat**.

The probe is read-only. It does not change KFC values, save files, profiles, or gameplay settings. It only reports which candidate resources and fields are visible to EML in the current game build.
