# Runtime Blueprint Authority Static Map v1

**RESEARCH / OFFLINE STATIC ONLY.** `0xCA90E0` and the `RSI+0xF0` cache are
connected to a placement-consumer family; `0x3E74B0` normalizes records with
dimensions, signed payload offsets, payload length, and compression state.
That is not sufficient to prove the cache is the world-commit authority.

Foundation and Wall already have distinct runtime dimensions/volume profiles
before `BuildingPlaceEvent`. The first common producer coupling selected
identity to decoded occupancy and commit volume remains unresolved. No runtime
observer or mutation is justified in this milestone.
