# Builder guide

Import an item catalog, search by name/category/tags, mark favorites, create a
build plan, and calculate material totals and shortages. Recommendations are
deterministic and offline. Saved plans do not place objects or mutate the game;
live placement assistance requires a separate authority and safety study.

## Beginner click path

1. Open **Building Studio** from the left navigation.
2. For the quickest start, select **Use Built-in Catalog**. This opens the
   bundled item list without asking you to find a file. Use **Open Catalog**
   only when you want a project-specific or exported catalog.
3. Use the search box to find an item, or choose a category. **Favorites only**
   narrows the list to items you saved for later.
4. Use **Recommended** to show the most relevant items for the selected
   category. Recommendations are suggestions only; they do not install or
   place anything.
5. Select **☆ Favorite** on furnishings you want to reuse. Favorites are saved
   locally for the next session.
6. Select **Create Plan from Built-in Catalog** for the bundled list, or
   **Create Plan from File** for a custom catalog. Enter quantities and give
   the plan a name such as `Castle bedroom`.
7. Select **Review Built-in Plan** for a plan made from the bundled list, or
   **Review Plan from File** for a custom catalog. Choose the saved plan and
   optionally enter the materials you already have. Control Center reports
   required totals and shortages.

Control Center also discovers locally generated custom furniture projects and
labels them **Custom furniture · research-only**. They can be included in an
offline plan, but this does not prove that the game exposes them through the
Carpenter menu or that the plan can place them automatically.

## What this feature does not do

The builder is an offline planning tool. It does not edit saves, consume
inventory, place objects, craft items, or claim multiplayer authority. Keep
the game closed when testing or changing any separate research-only content
project.
