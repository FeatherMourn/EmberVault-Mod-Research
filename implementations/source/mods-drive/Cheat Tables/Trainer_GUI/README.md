# Enshrouded Master Trainer GUI

Run `Run_Trainer_GUI.bat` from this directory. It launches the PySide6
dashboard from `.venv2` at approximately 1600x900, with fantasy header art,
navigation, search, CT-backed category cards, right-side safety information,
teleport/activity panels, and live process status. The sibling authoritative
table is `..\Enshrouded_Master_Trainer.CT`.

The GUI parses real records and uses the existing parser/labels/diagnostics.
Cheat Engine activation is intentionally disabled until a supported local
bridge can confirm attachment, table load, and per-record state. No button
reports activation based only on a click.
